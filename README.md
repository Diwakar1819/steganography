# BMP Steganography

A modular C implementation of LSB-based steganography using
24-bit uncompressed BMP images as carrier files.

## Project Status

Under development.

## Supported Carrier

- 24-bit BMP
- Uncompressed
- LSB-based embedding

## Planned Features

- Encode arbitrary binary files
- Decode embedded files
- Payload metadata
- Versioning
- Flags
- CRC32 integrity verification
- Capacity validation
- Robust BMP validation
